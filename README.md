# Process sensitivity analysis for the Hanford Site's 300 Area

This repository contains the calculation and plotting code associated with the
manuscript:

> *Quantifying Second- and Higher-Order Process Interactions Under Process Model
> and Parameter Uncertainty with an Application to Groundwater Reactive
> Transport Modeling*

The method estimates the complete set of first-order, second-order, third-order,
fourth-order, and total-effect process sensitivity indices under combined
process-model and parameter uncertainty.

## Repository contents

```text
calculation/              Sensitivity-index calculations
common/                   Shared grid and ensemble definitions
data/
  processed/              Nineteen calculated sensitivity-index arrays
  material_archives/      Five compact geological-configuration files
  raw/                    Instructions for supplying the raw model ensemble
figures/                  Final Figures 1-9 from the manuscript
plotting/                 Figure-generation scripts
requirements.txt          Python dependencies
```

The 19 arrays in `data/processed` comprise four first-order indices, six
second-order interactions, four third-order interactions, one fourth-order
interaction, and four total-effect indices.

## Installation

Python 3.10 or newer is recommended. Create an environment and install the
required packages:

```bash
conda create -n hanford-process-sensitivity python=3.11
conda activate hanford-process-sensitivity
python -m pip install -r requirements.txt
```

## Reproducing the figures

From the repository root, run:

```bash
python plotting/generate_all_figures.py
```

Regenerated PNG, PDF, and SVG files are written to `figures/generated`. The
numbered PNG files directly under `figures` are the versions embedded in the
final manuscript.

Figure 3 is the only composite figure that was not generated by a single Python
script. Its model cross-section and site legend are provided by
`plotting/figure03_model_cross_section.py` and
`plotting/figure03_site_legend.py`, while the complete manuscript composite is
preserved as `figures/Figure_03.png`.

## Recomputing the sensitivity indices

The included processed arrays are sufficient to reproduce Figures 5-9. To
recompute the indices, place the original model-output ensemble at:

```text
data/raw/doc_consum.npy
```

Then run:

```bash
python calculation/run_all.py
```

The calculation proceeds in dependency order: first-order and total-effect
indices, second-order interactions, and finally third- and fourth-order
interactions. The raw ensemble is approximately 27 GB and is therefore not
included in this repository.
